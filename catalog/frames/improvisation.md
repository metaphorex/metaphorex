Spontaneous, unscripted performance where participants create scenes in real
time by making and responding to offers. As a source domain, improvisation
provides a model of emergent collaboration: each contribution is an offer
that can be accepted (building the scene) or blocked (killing it). The frame
is structurally rich because it separates generative from destructive
responses, foregrounds the idea that creativity requires saying "yes, and"
rather than "no, but," and models how shared meaning emerges without
centralized planning.
