The analytical practices used to reason about security threats, defenses,
and risk. As a target domain, security analysis absorbs metaphors from
warfare (attack surfaces, defense in depth, blast radius), medicine
(vulnerabilities as weaknesses, patching as treatment), and biology
(immune response, adaptive defense). The domain's vocabulary reveals
which source frames dominate practitioner reasoning -- and which blind
spots each frame creates.
