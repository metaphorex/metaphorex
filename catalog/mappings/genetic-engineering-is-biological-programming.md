## What It Brings

Science fiction has long portrayed genetic engineering as a form of
programming -- writing code in DNA to produce designed organisms the way
a programmer writes code to produce designed software. From the "genetic
programs" of Brave New World's Bokanovsky process to the "designer
replicants" of Blade Runner to the bespoke organisms of Jurassic Park,
SF established the conceptual infrastructure that molecular biology later
adopted wholesale. Today, synthetic biologists routinely speak of "genetic
circuits," "gene expression programs," and "debugging" organisms.

Key structural parallels:

- **DNA as source code** -- the genome is treated as an instruction set
  that can be read, written, and edited. CRISPR-Cas9 is described as a
  "find-and-replace" tool. The metaphor maps the clean determinism of
  software (input -> process -> output) onto the messy, context-dependent
  expression of genes, making genetic engineering feel as tractable as
  editing a text file.
- **Organisms as compiled programs** -- the phenotype (visible traits) is
  framed as the "output" of running the genetic "code." This imports the
  software assumption that behavior is fully determined by instructions,
  that you can predict what the program will do by reading the source.
- **Bugs and debugging** -- unexpected phenotypic results are framed as
  "bugs" in the genetic program, implying they can be identified and
  fixed through systematic debugging rather than arising from irreducible
  biological complexity.
- **Version control and iteration** -- synthetic biology talks about
  "gene drives," "genetic libraries," and "standardized biological parts"
  (BioBricks) using vocabulary borrowed directly from software engineering,
  implying that biological components are modular and composable in the
  same way that software libraries are.

## Where It Breaks

- **Genes are not modular like functions** -- software functions can be
  composed with predictable interfaces. Genes interact through regulatory
  networks of staggering complexity: pleiotropy (one gene affecting many
  traits), epistasis (genes modifying each other's effects), and
  epigenetics (environmental factors altering gene expression without
  changing the sequence). There is no biological equivalent of a clean
  API. The programming metaphor systematically understates the
  interconnectedness of biological systems.
- **There is no compiler** -- in software, the path from source code to
  running program is deterministic and repeatable. In biology, the path
  from genotype to phenotype passes through protein folding, cellular
  environment, developmental timing, and ecological context. The same
  "code" produces different "outputs" depending on conditions that the
  metaphor renders invisible.
- **The metaphor hides the organism's agency** -- a program does not
  resist its programmer. An organism does. Cells have repair mechanisms
  that revert edits, immune systems that reject foreign genetic material,
  and evolutionary pressures that select against engineered traits in
  wild populations. The programming metaphor erases the biological
  subject's capacity to push back.
- **It normalizes engineering hubris** -- if genetic engineering is "just
  programming," then the question becomes merely technical: do we have
  good enough tools? The metaphor sidesteps the ecological and ethical
  questions that distinguish releasing modified organisms into ecosystems
  from deploying software into production. Software bugs crash programs;
  genetic "bugs" can crash ecosystems.
- **SF's own warnings are ignored** -- the irony is that the SF works
  that popularized this metaphor almost universally present it as a
  cautionary tale. Jurassic Park, Brave New World, Gattaca, and Blade
  Runner all dramatize the failure of the programming model. The metaphor
  survived the warnings embedded in its own source material.

## Expressions

- "Genetic code" -- the foundational expression, so deeply embedded that
  it is rarely recognized as metaphorical; DNA does not literally encode
  in the way software does
- "Gene editing" -- CRISPR described as an editing tool, importing the
  cut-copy-paste vocabulary of text processing
- "Reprogram cells" -- treating cellular identity as a software state
  that can be overwritten, as in induced pluripotent stem cell research
- "Biological programming language" -- explicit framing used by synthetic
  biology startups (Ginkgo Bioworks, Twist Bioscience) to describe their
  work to investors
- "Debug the genome" -- treating genetic diseases as software bugs that
  can be found and fixed through systematic analysis
- "Wetware" -- the body as biological hardware, the organic counterpart
  to silicon, a term coined in SF and adopted by biotech

## Origin Story

The computational metaphor for genetics predates molecular biology itself.
Erwin Schrodinger's *What Is Life?* (1944) described hereditary material
as a "code-script," and when Watson and Crick decoded DNA's structure in
1953, the vocabulary of information theory was ready and waiting. But it
was science fiction that dramatized the metaphor's implications: Aldous
Huxley's *Brave New World* (1932) envisioned mass-produced humans
designed to specification; Philip K. Dick's *Do Androids Dream of
Electric Sheep?* (1968) explored designed beings indistinguishable from
humans; Michael Crichton's *Jurassic Park* (1990) made "genetic
programming" a household concept by framing dinosaur resurrection as a
software project gone wrong. The metaphor reached its apotheosis with
the Human Genome Project (1990-2003), which was consistently described
in computational terms -- "reading the book of life," "decoding the
program." Today, synthetic biology companies market themselves using
programming metaphors with little acknowledgment that SF originated
this framing as warning, not aspiration.
