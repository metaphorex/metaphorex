## What It Brings

An interconnected structure of strands radiating from no single center, where
any point can be reached from any other by following connections. The spider
web maps onto hyperlinked documents with genuine structural fidelity:
interconnected nodes, no mandatory hierarchy, multiple paths between any
two points, and a topology that is grown incrementally rather than designed
top-down.

- **Decentralized connectivity** -- a spider web has no single center that
  all strands must pass through (orb webs have a hub, but the structural
  emphasis is on the mesh of connections). The World Wide Web was designed
  with the same principle: no central server, no master index, just
  documents linking to other documents. The metaphor made decentralization
  feel natural and organic rather than chaotic and unmanaged.
- **Growth by accretion** -- a spider builds its web strand by strand, and
  each new strand strengthens the whole. The web grows the same way: each
  new page with links increases the connectivity of the entire network. The
  metaphor captures the emergent property that no single page is essential
  but the aggregate is robust. Tim Berners-Lee's design explicitly relied
  on this: anyone can add a strand.
- **Navigation as traversal** -- you move through a spider web by following
  strands from node to node. Web "browsing" and "surfing" are later
  metaphors layered on top, but the underlying model is strand-following:
  clicking a hyperlink is walking along a thread to the next junction.
  The web metaphor made hypertext navigation intuitive to people who had
  never used a computer network.

## Where It Breaks

- **Spider webs are traps** -- a spider web exists to catch prey. The
  spider sits at the center (or nearby), waiting for vibrations that signal
  something has been caught. The World Wide Web was designed as a commons,
  not a trap. Yet the predatory implication, invisible for the first
  decade, has become disturbingly apt: attention-harvesting platforms,
  dark patterns, and addictive design have made the web feel more like a
  trap than a commons. The metaphor's hidden predatory logic has, in a
  sense, become prophetic.
- **Spider webs have a single architect** -- one spider builds one web for
  one purpose. The World Wide Web is built by millions of independent
  actors with conflicting purposes. The metaphor implies a coherent design
  where there is only emergent structure. Nobody designed the web's current
  shape; it resulted from billions of individual linking decisions. The
  architectural coherence the metaphor implies does not exist.
- **Webs are fragile** -- a spider web can be destroyed by a gust of wind
  or a careless hand. The internet (which the web runs on) was designed
  for resilience: packet switching, redundant routing, no single point of
  failure. The fragility of literal webs maps poorly onto a network built
  to survive nuclear attack. The web is sticky and interconnected like a
  spider web, but robust in ways that spider webs are not.
- **The web is not sticky for the user** -- a spider web's stickiness is
  the point: prey that touches it cannot leave. Web users can navigate
  away with a click. The stickiness that does exist -- algorithmic feeds,
  infinite scroll, notification loops -- was engineered later, against
  the original design, and it maps to the predatory dimension the metaphor
  always contained but nobody initially noticed.

## Expressions

- "Website" -- a site on the web, a location where strands converge, now
  so dead that nobody pictures a spider when they hear it
- "Web page" -- a single document in the web, mixing the web metaphor
  with a book metaphor (pages) without anyone finding the combination odd
- "Web browser" -- a tool for moving through the web, though "browsing"
  imports a different metaphor entirely (leisurely shopping)
- "Webcrawler" / "web spider" -- programs that traverse the web by
  following links, the only common usage that still acknowledges the
  arachnid origin
- "The dark web" -- the hidden, unindexed portion, extending the web
  metaphor with a visibility dimension (dark corners of the web where
  the light does not reach)
- "Caught in the web" -- the rare expression that resurrects the trap
  dimension, used for internet addiction or information overload

## Origin Story

Tim Berners-Lee chose "World Wide Web" in 1989 while working at CERN. In
his 1999 memoir *Weaving the Web*, he describes considering other names:
"Information Mesh," "The Information Mine" (rejected because it abbreviated
to TIM), and "Mine of Information" (rejected for the same vanity concern
in reverse). "World Wide Web" won because it captured the decentralized,
interconnected structure he envisioned.

The spider web metaphor was deliberate. Berners-Lee wanted a name that
evoked organic interconnection rather than hierarchical organization. The
alternatives he rejected -- mesh, mine -- were either too technical or
too extractive. "Web" felt natural, collaborative, and non-threatening.
The alliteration of "World Wide Web" helped too: it was memorable in a way
that "Global Hypertext System" was not.

The abbreviation "WWW" ironically takes longer to say than "World Wide Web"
(nine syllables vs. three), which is why most people just say "the web."
This abbreviation completed the metaphor's death: "the web" is now a
proper noun that refers to a specific technology, not a description of
a topology. Children who grow up using "the web" do not picture a spider.
The arachnid survives only in "webcrawler" and "spider," terms used by
search engine engineers who appreciate the zoological irony.
