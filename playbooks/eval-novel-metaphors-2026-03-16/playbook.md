## Extraction Strategy

Each candidate is a standalone conceptual metaphor entry. The Miner should:

1. Create branch `mine/eval-novel-metaphors-2026-03-16/<slug>`
2. Write the entry in `catalog/entries/<slug>.md` following the standard schema
3. Create any missing frames referenced by the entry
4. Search the web for prior art, academic references, and real-world usage
   examples -- particularly for Transfers and Limits sections (per curator
   comment on the issue)
5. For `technical-decisions-are-judicial-rulings`, explicitly reference the
   "Benevolent Dictator For Life" (BDFL) concept as applied to Guido van
   Rossum (Python) and Linus Torvalds (Linux) -- per curator feedback

- **Frame creation**: Several candidates reference source frames that may not

  same PR (validator enforces this).
- **`influence-is-physical-force` spans scenarios**: This candidate appeared

  note both contexts in the entry body.

  transfers and limits sections for each." This is not optional.
- **18 candidates, well under 100-issue cap**: No sub-issue overflow concern.
